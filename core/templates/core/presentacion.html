Cómo fluye una petición

# core/views.py
def presentacion(request):
    return render(request, "core/presentacion.html")

# config/urls.py
path("presentacion/", views.presentacion, name="presentacion")

Levantar el proyecto

Del cero al servidor

Entorno virtual

virtualenv venv  ·  venv\Scripts\Activate.ps1

Instalar Django

pip install django  ·  export en requirements.txt

Crear proyecto y app

startproject config .  ·  startapp core

Migrar y ejecutar

python manage.py migrate  ·  python manage.py runserver
